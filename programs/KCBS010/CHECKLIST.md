## テスト項目
#### 1.正常系：チェック処理
- [x] 存在する日付の場合、復帰コードがスペースで返ってくること
- [x] うるう年の2月29日が、復帰コードスペースで返ってくること
- [x] 月が0または13の時は、最大日数に0がセットされること
- [x] 31日まである月の31日が正常に処理されること
- [x] 30日まである月の30日が正常に処理されること
- [x] 閏年の判定で400で割れる年が正常に処理されること
- [x] 閏年の判定で400で割れるが100で割れない年が 'E' になること
- [x] 閏年の判定で4で割れる年が正常に処理されること

### 2.正常系：西暦の桁変換
- [x] 年下2桁が90以上の時、年上2桁に19がセットされていること
- [x] 年下2桁が90の時、年上2桁に19がセットされていること
- [x] 年下2桁が90未満の時、年上2桁に20がセットされていること

### 3.異常系：復帰コードに"E"が入るとき
- [x] 入力値の日付に数字以外が含まれていると復帰コード"E"が返ること
- [x] 月が1～12の範囲外の場合、復帰コード"E"が返ること
- [x] 月が00の場合、復帰コード"E"が返ること
- [x] 月が13の場合、復帰コード"E"が返ること
- [x] 日が各月の最大日数を超えていると復帰コード"E"が返ること
- [x] 日が0の場合、復帰コード"E"が返ること
- [x] うるう年でない年の2月の最大日数が29日の時復帰コード"E"が返ること
