# KJBM011 単体テストチェックリスト

## 形式チェック（正常系・異常系）

## テスト項目
#### 1.処理全体の確認
- [x] 開始メッセージ *** KJBM011 START *** が表示されること
- [x] カーソルを開くとSQLCODE = 0と表示されること
- [x] 読み込むテーブルの数だけ、FETCH SQLCODE = 0と表示されること
- [x] 読み込むテーブルがなくなると、FETCH SQLCODE = 100と表示されること
- [x] 表示される出力ファイルに書き込んだ件数が読み込まれたレコード数と一致していること
- [x] 終了メッセージ *** KJBM011 END *** が表示されること

### 2.正常系：編集要領に適した転送
- [x] 予備項目や値を設定していない項目がスペースになっていること
- [x] 処理された後の出力ファイルに1レコード100桁で入っていること
- [x] データ区分にはCMJUCHU_DATA_KBNの値が入っていること
- [x] 受注番号にはCMJUCHU_JUCHU_NOの値が入っていること
- [x] 受注日付の6桁(YYMMDD)にはCMJUCHU_JUCHU_DATEの値が入っていること
- [x] 商品番号にはCMJUCHU_SHOHIN_NOの値が入っていること
- [x] 数量にはCMJUCHU_SURYOの値が入っていること
- [x] 受注日付の年の上2桁が00で固定されていること
- [x] エラー区分テーブルには空白(" ")がセットされていること
- [x] 商品名には空白(" ")がセットされていること
- [x] 単価には0がセットされていること
- [x] 金額には0がセットされていること
- [x] 受注番号に数値以外が入ってもエラーにならずに入ること
- [x] 日付に数値以外が入ってもエラーにならずに入ること
- [x] 商品番号に数値以外が入ってもエラーにならずに入ること
- [x] 単価に数値以外が入ってもエラーにならずに入ること
- [x] 金額に数値以外が入ってもエラーにならずに入ること
