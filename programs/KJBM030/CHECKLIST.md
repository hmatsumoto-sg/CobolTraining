# KJBM030 単体テストチェックリスト

## 形式チェック（正常系・異常系）

## テスト項目
#### 1.処理全体の確認
- [x] 開始メッセージ *** KJBM030 START *** が表示されること
- [x] 入力ファイルが0件の時に、「ITF = 0,IMF = 0,OTF = 0」となり正常に終了すること
- [x] 表示される入力ファイルを読み込んだ件数が読み込むレコード数と一致していること
- [x] 表示されるマスタファイルを読み込んだ件数が入力ファイルとマッチしたレコード数と一致していること
- [x] 表示される出力ファイルを読み込んだ件数が出力されたレコード数と一致していること
- [x] 受注データの読み込みが商品マスタより早く読み終わった時、残りのマスタを読み飛ばして正常に終了すること
- [x] 商品マスタが先に終わった時、残りの受注データがすべてマスタ不一致として処理されること
- [x] 終了メッセージ *** KJBM030 END *** が表示されること

### 2.正常系：仕様書「処理詳細」に基づくエラー区分(5)に対する処理
- [x] エラー区分(5)になにか(スペース以外)入っているレコードはマッチング処理をしていないこと
- [x] エラー区分(5)になにか(スペース以外)入っているレコードは入力ファイルの情報をそのまま出力していること


### 4.正常系：仕様書「マッチング処理」に基づくマッチング処理
- [x] 受注チェックファイルの商品番号と商品マスタの商品番号が同一の時、商品マスタの商品名が出力されていること
- [x] 受注チェックファイルの商品番号と商品マスタの商品番号が同一の時、商品マスタの単価が出力されていること
- [x] 受注チェックファイルの商品番号と商品マスタの商品番号が同一で、エラー区分(6)がスペースの時、受注チェックファイルの数量と商品マスタの単価を掛け合わせたものが出力されていること
- [x] 受注チェックファイルの商品番号と商品マスタの商品番号が同一の時で、エラー区分(6)がスペース以外の時は、0が入っていること
- [x] 受注チェックファイルの商品番号より商品マスタの商品番号が大きい時、エラー区分(5)に2が入っていること
- [x] 受注チェックファイルの商品番号より商品マスタの商品番号が大きい時、次の受注チェックファイルだけ読み込んでいること
- [x] 受注チェックファイルの商品番号より商品マスタの商品番号が小さい時、次の商品マスタファイルのみ読み込んでいること
